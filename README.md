### Hi, I'm João Quintão

Full-stack developer from Belo Horizonte, Brazil, with a double degree in Computer Science (PUC Minas) and Computer Engineering (IPG, Portugal). Before web development I worked with data: Power BI dashboards, SQL and Python automation for companies like MRV Engenharia.

Today I build software for tabletop RPGs: **[Quinto Dado](https://quinto-dado.vercel.app)**, a web platform in production for running game tables, and complete game systems for Foundry VTT.

Italian–Brazilian dual citizen, open to full-stack and data roles in Europe or remote.

#### Featured work

- **[Quinto Dado](https://github.com/devjohnfifth/QuintoDado)**: game-table applications, a supplement library and an admin panel. Next.js 15, React 19, TypeScript, PostgreSQL/Supabase with row-level security, Vitest.
- **[Assimilação RPG for Foundry VTT](https://github.com/devjohnfifth/assimilacao-rpg-foundry)**: unofficial game system with custom symbol dice, character sheets that mirror the printed book and a real-time conflict tracker shared by GM and players.
- **[Ordem Paranormal RPG 2 playtest for Foundry VTT](https://github.com/devjohnfifth/ordem-paranormal-2e-foundry)**: unofficial game system installed by manifest link, with 30+ published releases.
- **[Distributed key-value database](https://github.com/devjohnfifth/projects/tree/main/Computacao%20distribuida/distributed-db-main)**: replicated over gRPC with two-phase commit, Bully leader election, a write-ahead log and Lamport clocks, all implemented by hand.

**Stack:** TypeScript · React / Next.js · Node.js · PostgreSQL / Supabase · Python · Java · C · SQL · Power BI
